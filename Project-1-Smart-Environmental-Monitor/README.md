# 🌡️ Smart Environmental Monitor

## 📌 Description

This project is a **Smart Environmental Monitor** that measures temperature and humidity using a **DHT22 digital sensor**.

An **Arduino Uno** is used to read the sensor data. The temperature and humidity values are displayed on the **Serial Monitor every 2 seconds**.

The project is implemented and tested using the **Wokwi simulator**.

## 🛠️ Components Used

- 🔌 Arduino Uno
- 🌡️ DHT22 Temperature and Humidity Sensor
- 💻 Wokwi Simulator

## ⚙️ Working Principle

1. 🌡️ The DHT22 sensor measures the surrounding temperature and humidity.
2. 🔄 Arduino Uno reads the sensor data.
3. 🌡️ The temperature is displayed in degree Celsius.
4. 💧 The humidity is displayed as a percentage.
5. ⏱️ The readings are updated every 2 seconds.

## ▶️ How to Run

1. 💻 Open the project in Wokwi.
2. ▶️ Start the simulation.
3. 📊 Open the Serial Monitor.
4. 👀 Observe the temperature and humidity readings.
5. ⏱️ The values are updated every 2 seconds.
